# Footer コンポーネント仕様

## 目的
サイト下部に表示される共通フッター。

## Props
なし（独立コンポーネント）

## 表示
- 左: コピーライト表記（年は動的に生成）
- 右: GitHub リンク（アイコン付き）

## デザイン指針
- レイアウト: `flex`、sm以上で左右に分割（モバイルは縦積み中央寄せ）
- ライト背景: `bg-slate-50` + `border-t border-slate-200`
- ダーク背景: `bg-slate-900` + `border-t border-slate-700/60`
- テキスト: `text-slate-500 dark:text-slate-400`
- パディング: `py-8`
- 最大幅: `max-w-5xl`

## 受入条件
- [ ] 著作権年が現在の年で表示される
- [ ] GitHub リンクがアイコン付きで表示される
- [ ] ライト/ダーク両モードで適切な背景・テキスト色になる
