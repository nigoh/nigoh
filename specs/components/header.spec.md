# Header コンポーネント仕様

## 目的
サイト全体で表示される固定ナビゲーションヘッダー。

## Props
なし（独立コンポーネント）

## 表示
- 左: サイトロゴ「H.Nigo」（`font-bold`、トップページへのリンク）
- 右（デスクトップ）: ナビゲーションリンク（About / Skills / Timeline / Portfolio / Contact）+ テーマ切替ボタン（太陽/月アイコン）
- 右（モバイル）: テーマ切替ボタン + ハンバーガーメニューボタン

## モバイルメニュー
- ハンバーガーメニュー押下でドロップダウン表示
- ナビリンクを縦積み表示
- リンク押下でメニューを閉じる

## テーマ切替
- ボタン押下で `<html>` の `dark` クラスをトグル
- `localStorage` に `'theme'` キーで `'light'` / `'dark'` を保存
- ダーク時: 太陽アイコン表示、ライト時: 月アイコン表示

## デザイン指針
- `position: fixed` で画面上部に固定 (`z-50`)
- ライト背景: `bg-white/80` + `backdrop-blur-md` + `border-b border-slate-200`
- ダーク背景: `bg-slate-900/80` + `backdrop-blur-md` + `border-b border-slate-700/60`
- 高さ: 64px (`h-16`)
- 最大幅: `max-w-5xl`（コンテンツ中央寄せ）
- ホバー: `hover:bg-slate-100 dark:hover:bg-slate-800` + テキスト色変更

## 受入条件
- [ ] スクロールしてもヘッダーが画面上部に固定される
- [ ] ナビゲーションリンクがスムーススクロールで遷移する
- [ ] マウスホバー時にリンクの色が変わる
- [ ] テーマ切替ボタンでライト/ダーク切替が動作する
- [ ] テーマ設定が `localStorage` に保持される
- [ ] モバイル（< 640px）でハンバーガーメニューが表示される
- [ ] モバイルメニューのリンク押下でメニューが閉じる
- [ ] ライト/ダーク両モードで適切な背景・テキスト色になる
