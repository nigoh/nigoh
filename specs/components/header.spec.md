# Header コンポーネント仕様

## 目的
サイト全体で表示される固定ナビゲーションヘッダー。

## Props
なし（独立コンポーネント）

## 表示
- 左: サイトロゴ「H.Nigo」（トップページへのリンク）
- 右: ナビゲーションリンク（Home, About, Skills）

## デザイン指針
- `position: fixed` で画面上部に固定
- 背景: 半透明白 + `backdrop-blur`
- 高さ: 64px (h-16)
- 最大幅: `max-w-5xl`（コンテンツ中央寄せ）

## 受入条件
- [ ] スクロールしてもヘッダーが画面上部に固定される
- [ ] ナビゲーションリンクがスムーススクロールで遷移する
- [ ] マウスホバー時にリンクの色が変わる
