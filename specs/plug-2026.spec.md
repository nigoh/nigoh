# プラグ（pipe-in のデザイン）への刷新 2026

## 目的

サイトの見た目を **バウハウス（三原色・極太の欧文・角ばった図形）→ pipe-in の「プラグ」** に入れ替える。
pipe-in（`nigoh/pipe-in` の `docs/design/README.md`・D0030・D0094）の色・文字・角・影・アイコンを土台にし、
サイトを「パイプ作業台」に見立てて組む。1 ページ完結・セクション構成・掲載内容・ビルド時の自動取得
（GitHub・Zenn）・除外パターン `excludedRepos` はそのまま。

サイト所有者が選んだ案（デザイン案のアーティファクト「nigoh プラグ案」）:

- **案 A 作業台** を土台にする。
- **案 D のロゴ**（「nigoh」の i の点がコンセントで、コーラルのプラグが差さる）をヘッダーとヒーローに使う。
- **案 B の経歴の帯グラフ**（時系列）を経歴に使う。
- **案 C の作品ボード**（列に振り分けたカード）を作品に使う。

この仕様は `specs/bauhaus-2026.spec.md`・`specs/redesign-2026-bold.spec.md`・`specs/components/*` の
見た目の決まりを置き換える（旧仕様は履歴として残す）。

## パレット（唯一の出典 = `tailwind.config.mjs` の `plug`）

色は役の名前で呼び、明るい画面と暗い画面で同じ名前に別の値を当てる。値は pipe-in と同じ
（`canvas`・`ok-ink`・`logo-*` だけサイト用に足した）。

| 役 | トークン | 明るい | 暗い | 使う所 |
| --- | --- | --- | --- | --- |
| 地 | `bg` | `#f6f6f4` | `#161514` | 上の帯の下・ダイアログの外 |
| 作業台の地 | `canvas` | `#eceae6` | `#100f0e` | ページ全体の地（薄い点の方眼） |
| 面 | `panel` | `#ffffff` | `#211f1d` | セクションのブロック・上の帯・流れ |
| 列 | `col` | `#ecebe7` | `#1d1b19` | ブロックの中のまとまり・ボードの列 |
| 線 | `line` | `#e4ded8` | `#36322f` | 区切り・押せないまとまりの枠 |

- コーラルは「人が手を出す所」だけ。ティールは「流れている・選んでいる所」。
- 状態は色だけで伝えない：アイコンの形（✓ の丸＝完了・一区切り、回る矢印＝いまここ・製作中、点線の丸＝まだ）と言葉を添える。
- CSS 変数 `--c-*` は `global.css` で `theme('colors.plug.<mode>.*')` から作る。Tailwind のクラスは `ui-*`（`bg-ui-panel` など、`--c-*` を指す）。
- 暗い画面は `prefers-color-scheme` に従い、手動の切り替え（`data-theme`・`localStorage.theme`）が勝つ。

## 文字

- 見出し・本文：Zen Kaku Gothic New（400・500・700・900）。見出しは 900。
- 年・期間・割合・数：JetBrains Mono（`font-mono`・`tabular-nums`）。
- ロゴだけ Outfit 600 をアウトライン化した SVG（pipe-in のロゴと同じ書体・同じ太さ）。
- 本文と操作の文字は 16px 以上、注・札は 14px 以上（D0094）。本文の行間は 1.7。
- 見出しは日本語（自己紹介・スキル・AI と開発・経歴・作品・連絡）に、小さな英語の札（`about` など mono）を添える。大文字の英語の大見出しはやめる。

## 角と影（やわらか）

- 札 6px・ボタン 8px・カード 14px・面（ブロック）20px・チップ 999px。
- まとまりは線の輪で囲まず、明るい画面はやわらかい影でまとめる。暗い画面は影が見えにくいので 1px の輪を残す。

## 構図（案 A 作業台）

> **2026-11 置き換え**: この節の組み方（縦に積んだブロックと左のケーブル・右に固定の目次・スクロールで進む状態の札・セクションの中身の表）は
> [`shell-2026.spec.md`](shell-2026.spec.md)（1 画面の作業台・差して切り替える）に置き換えた。色・文字・角・影・ロゴ・アイコンは引き続きこの仕様。

```
上の帯（固定 56px）: [ロゴ nigoh] ............ [いまの段（スマホ）] [明るい/暗い]
ページの地: 作業台（canvas + 点の方眼）
┌ 流れのケーブル（ティール 3px・左） ───────────────┐  ┌ 流れ（目次・lg 以上で右に固定）┐
│ ●─[プラグ|コンセント] 01 はじめ（start・ヒーロー）  │  │ ✓ 01 はじめ                   │
│ ●─[プラグ|コンセント] 02 自己紹介                   │  │ ↻ 02 自己紹介（いまここ）     │
│ ●─ … 03 スキル / 04 AI と開発 / 05 経歴 / 06 作品  │  │ ◌ 03 スキル …                 │
│ ╰─[プラグ|コンセント] 07 連絡（end）                │  └──────────────────────────────┘
```

- セクションはそれぞれ 1 つの **ブロック**（`<section>`・面の色・角 20・影）。ブロックの左の縁に
  **ティールのコンセント**があり、左を縦に走る **ケーブル**（ティール 3px）から枝が出て、
  **コーラルのプラグ**がコンセントに差さる。枝分かれの所にだけ点を置き、最後のブロックはケーブルの角を半径 12px で丸める。
- ブロックの頭：アイコンの札（Lucide）・見出し（日本語 900）・英語の札（mono）・状態の札（完了／いまここ／まだ）。状態の札は飾り（`aria-hidden`）で、同じ情報は目次が持つ。
- **流れ（目次）**：lg 以上はページの右に固定（sticky）。7 段を縦に並べ、読み終えた段は ✓ 完了、いま読んでいる段は回る矢印、まだの段は点線の丸。`aria-current` を付ける。
  lg 未満は上の帯の「いまの段」ボタンから、同じ一覧をダイアログ（`<dialog>`）で開く。
- ヒーロー（01 はじめ）は高さを内容に合わせる（100vh・sticky の尺は使わない）。ロゴ「nigoh」（大）・肩書き・
  一言「低レイヤーから、アプリまで.」（句点はコーラル）・紹介文・主のボタン（GitHub＝コーラル）と従のボタン（Zenn）。

## ロゴ（案 D）

- `src/components/Logo.astro`。Outfit 600 の n・ı（点の無い i）・g・o・h をアウトライン化して並べ、i の点の位置に
  **ティールのコンセント**（穴 2 つ、プラグの向きに傾ける）を置く。h の右上のコーラルの点からケーブルが「go」の上を越え、
  **コーラルのプラグ**がコンセントの手前まで来ている形（pipe-in のロゴの左右を返した兄弟）。
- 色は `logo-teal` / `logo-coral`（暗い画面で明るい値）。穴は mask で抜く（地が透ける）。同じページで 2 回使うので mask の id は呼び出しごとに変える。
- 書体の出典（Outfit・SIL OFL 1.1）をコンポーネントのコメントに書く。favicon は同じプラグとコンセント。

## 動き

- ブロックが画面に入ると、プラグがコンセントへ 12px 進んで差さり、コンセントの輪が一度だけ広がる（0.5 秒・`transform` と `opacity` だけ・1 回だけ）。
  差さる前はコンセントの穴が見え、差さった後は穴が隠れる。
- `prefers-reduced-motion: reduce` と JS 無しでは、最初から差さった形で止まる（読む内容は動きに頼らない）。
- やめるもの：ポスターのイントロ・幾何のカーソル・3D のアクセント・マーキー・版ずれのホバー・紙の粒子・視差・250vh のヒーロー。
