# トップページ仕様

## 目的
訪問者に H.Nigo の概要を伝えるメインページ。

## パス
`/` (`src/pages/index.astro`)

## セクション構成

### 1. Hero セクション
- 役割表記: 「Software Engineer」
- 名前: 「H.Nigo」（大きなフォント）
- 自己紹介テキスト（2行程度）
- CTAボタン「About Me」→ About セクションへスクロール
- 背景: グラデーション（gray-50 → white → emerald-50）
- 高さ: 画面の 80% 以上（`min-h-[80vh]`）

### 2. About セクション
- プロフィール説明（生年、在住地、経歴概要）
- 基本情報テーブル（名前、所在地、職業、趣味）
- 2カラムレイアウト（md以上）

### 3. Skills セクション
- スキルカード（4つ）: C/C++, Rust, Python, その他
- 各カードに名前と簡単な説明
- グリッドレイアウト（sm:2列、lg:4列）

## デザイン指針
- セクション間のパディング: `py-24`
- About は白背景、Skills はグレー背景（交互）
- カードは `rounded-xl` + `shadow-sm` + ホバーで `shadow-md`

## 受入条件
- [ ] Hero セクションが画面の大部分を占める
- [ ] About Me ボタンクリックで About セクションへスムーススクロール
- [ ] Skills カードがレスポンシブにグリッド表示される
- [ ] 全セクションがモバイルで正しく表示される
