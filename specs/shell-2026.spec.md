# 1 画面の作業台（差して切り替える）2026

## 目的

ページが縦に長い（PC で約 7.7 画面・スマホで約 13.4 画面。いちばん長いのはスキル）のを直す。
見た目（`plug-2026.spec.md` の色・文字・角）と物理の遊び（`physics-2026.spec.md`）は変えず、**組み方（UI・UX）**を変える。

サイト所有者が選んだ案（デザインのキャンバス「nigoh UI/UX 見直し」）: **案 A 差して切り替える**。
経歴で採用した「プラグを差すと見える」を、サイト全体に広げる。左の「流れ」の段にプラグを差すと、右にその段だけ出る。

この仕様は `plug-2026.spec.md` の「構図」（縦に積んだブロックと左のケーブル・右に固定の目次・スクロールで進む状態の札）と、
`physics-2026.spec.md` の C の置き方（帯グラフと一覧を別に置く）を置き換える。

│ ┌ 流れ ─────┐   ┌ 出力（差した段だけ）──────┐ │      │ 出力（差した段だけ）   │
│ │ 01 はじめ ◉═╗  │                          │ │      │ …                     │

│ │ 傾き（つまみ）│   │  ← 前へ   01/07   次へ → │ │      │ [04 AI] [▮05 経歴] [06] │

- **流れ（段の一覧）**：7 段（はじめ・自己紹介・スキル・AI と開発・経歴・作品・連絡）。番号（mono）・名前・ひとこと（件数など）。
  - PC：左に固定（sticky）。各段の右の縁にティールのコンセント。出力の面の左の縁から出たケーブル（ベルレのひも）の先の
    コーラルのプラグが、いまの段に差さっている。段を押すとプラグが飛んで差さる。プラグをつまんで別の段に差してもよい。
    どこにも差さずに離すと、もとの段に戻る（何も出ない画面は作らない）。下に「傾き」のつまみ。
  - スマホ：画面の下に固定した帯。段のチップを横に送る。いまの段はティールで塗り、プラグの印を付ける（ひもは出さない）。
- **出力（面）**：差した段だけを出す。下に「← 前へ」「次へ →」（行き先の名前つき）と `05 / 07`。PC では面の高さを画面に合わせる（1 画面）。
- 段を切り替えたら、ページの先頭へ戻し、アドレスの `#id`（`#career` など）を書き換える。`#id` 付きで開くと、その段から始まる。

| 02 自己紹介 | 2 列：名前などの表 ／ 一言と紹介文 |
| 03 スキル | **分野を切り替える**タブ（言語・プラットフォーム・開発と基盤・AI 駆動開発）。選んだ分野だけ、砂の管と項目の一覧を横に並べる |
| 04 AI と開発 | 2 列：道具箱 ／ 6 つの道具の札（題と 1 行。開くと全文）。下に関心ごと 3 つ |
| 05 経歴 | **帯グラフと一覧を 1 つに**：仕事の札の中に小さな帯（2016〜2028 の目盛り）。プラグを差した仕事が右のモニターに出る |

## ふるまい

- 段の一覧は **タブ**として扱う（`role="tablist"`・`tab`・`tabpanel`、`aria-selected`、矢印キー・Home・End で移る。Tab キーは選んでいる段だけに止まる）。
- 「前へ」「次へ」で切り替えたときは、出力の面の見出しへフォーカスを移す。
- 分野・作品の切り替えは `aria-pressed` の下線つきのタブ（最初は丸いチップだった。「スマホの見直し」で変えた）。
- 見えていない段の物理は止まる（`loop.ts` が見えているものだけ動かす）。はじめて見えたときに大きさを測り直す。
- **JS 無し**：7 段を縦にぜんぶ並べる（今までどおり読める）。段の一覧はページ内リンク。分野・作品の切り替えは出さず、ぜんぶ並べる。
- 動きを減らす設定：プラグは飛ばずにすぐ差さる。ひもは垂れた形で止まる。

## スマホの見直し（実機で見たあと）

デザインのキャンバス「nigoh UI/UX 見直し」の「スマホの見直し」のページで決めた（サイト所有者が承認）。

- **大きさ（640px 未満）**：全体を少し小さくする。本文 15px・注 13px・小さな mono 12px（文字の基準を 16px → 15px にして、rem の大きさと余白をまとめて縮める）。
  見出し 22px。上の帯 48px。押せる所の高さは 40px（下の帯のチップ・ボタン・アイコンのボタン）。
  PC（640px 以上）は今までどおり（本文 16px・注 14px・押せる所 44px）。
- **砂のロゴ**：受け皿の中にボタンを重ねない。ボタン（傾き・もとに戻す）と案内の文は、受け皿の下の 1 行に出す（スマホはアイコンだけ・PC は文字つき）。
  砂の粒を細かくする（スマホ 2px・PC 3px。前はどちらも 3px）。
- **前へ / 次へ**：1 行に収める（← 前の段の名前｜05 / 07｜次の段の名前 →。「次は」の文字は付けない）。
- **切り替え（スキルの分野・作品の種類）**：丸いチップをやめ、下線つきの文字のタブを 1 行に並べる（入りきらないときは横に送る）。
- **経歴（640px 未満）**：案 1 年表。左に年（mono）、真ん中に縦のケーブルとコンセント、右に仕事の名前。
  仕事を押すとプラグがそこに差さり、その場で状態・期間・工程・技術が開く（開くのは 1 つ）。最初は今の仕事が開いている。
  640px 以上は、今までどおり仕事の札とモニターとひも。JS 無しでは、どちらの幅でも全部の仕事が読める。
