# 物理の遊び（砂・ケーブル・剛体）2026

## 目的

`plug-2026.spec.md` の土台（作業台・ブロック・ケーブル・プラグ）は変えずに、物理演算で遊べる所を足す。
「土台はしっかり、技術力のある遊び心」。スマホは傾き（ジャイロ）で、PC は傾きのつまみ・なぞる・つまむで動く。

サイト所有者が選んだ案（アーティファクト「nigoh 物理の遊び案」）: **A・B・C・D の全部**。
C は「プラグを差すと、その経歴が見える」形にする。ジャイロは「ボタンで始める」（iPhone はボタン、Android は押さなくても拾う）。

## 共通（`src/scripts/physics/`）

| ファイル | 役目 |
| --- | --- |
| `gravity.ts` | 重力の向き `G`（既定は下向き `0, 1`）。ジャイロ（`deviceorientation`、画面の向きで回す）・傾きのつまみ・キーから変える。iPhone は `requestPermission` をボタンから呼ぶ |
| `loop.ts` | 1 本の `requestAnimationFrame`。見えている物理だけ動かす（IntersectionObserver）。10 秒さわらなければ休む。タブが隠れたら止める |
| `colors.ts` | 色を `--c-*` から読む（砂の色は teal・logo-coral・edge・teal-ink を `col` に 0/14/28% 混ぜた 3 段）。明るい/暗いの切り替えで読み直して描き直す |
| `sand.ts` | 砂のセル・オートマトン。重力の向きの先から順に、空いたマスへ 1 マスずつ（真っ直ぐ → 斜め 2 方向。斜めは重力の角度に寄せて選ぶ）。固まった粒（`stuck`）は動かない |

- **動きを減らす設定**（`prefers-reduced-motion: reduce`）：自動では動かさない。止まった形（固まったロゴ・たまった砂・垂れたケーブル・積んだ札）で出し、さわった直後の 1.5 秒だけ動く。ジャイロもボタンで選んだときだけ。
- **JS 無し**：物理は出さず、今までの静かな見た目（ベクターのロゴ・CSS の目盛り・経歴の一覧）にする。
- **読みやすさ**：物理の絵はすべて `aria-hidden`。読む内容（名前・スキルの数・経歴・道具）は文字で出す。
- **重さ**：canvas は画素比 2 まで。砂は `ImageData` を 1 回書くだけ。matter.js は道具箱が近づいてから読み込む（別のチャンク）。

## A 砂のロゴ（01 はじめ）

- ヒーローの上に「砂の受け皿」（列の色の面・角 14）。ロゴ「nigoh」（`logoShape.ts` の下絵）を砂粒で描き、粒は固まっている。下には少し砂がたまっていて、いつも傾きに合わせて流れる。
- なぞる（カーソル・指）と、その周りの粒がほどけて落ちる。押したままにすると砂が出る。はっきり傾けると（横に 0.4 以上、または上向き）ロゴ全体がほどける。
- 「もとに戻す」でロゴを描き直す。iPhone では「傾きで動かす」ボタンを出す（Android は自動）。
- 見出し（h1）は `H.Nigo（nigoh）` を文字で持つ（見た目は隠す）。

## B 砂のメーター（03 スキル）

- 分野ごとのまとまりの上に、項目ごとの管（ガラス）を並べ、その分野が見えると（スキルの段を選ぶ・分野を切り替える）砂がレベルの数だけたまる（粒の数＝レベル×マスの数。立てると目盛りの高さにそろう）。管の下に短い名前と数（mono）。
- 傾けると砂の面が斜めになる。数は文字のまま変わらない。
- 下に項目の一覧（正式な名前・説明・読み上げ用のレベル）。JS 無しでは管は CSS の塗りで高さを出す。

## C 差すと見えるケーブル（05 経歴）

> 置き方は [`shell-2026.spec.md`](shell-2026.spec.md) で変えた：帯グラフは別に置かず、仕事の札の中の小さな帯にした。ひもの動きは `physics/plugBoard.ts` にまとめ、
> 同じ部品を「流れ」（段の切り替え。どこにも差さずに離すと、もとの段へ戻る）にも使う。

- 左に仕事の一覧（期間・短い名前）。それぞれの右の縁にティールのコンセント。右に「出力」の面（モニター）。モニターの左の縁から出たケーブル（ベルレ積分のひも）の先のコーラルのプラグを、どれかの仕事のコンセントに差すと、モニターにその仕事（期間・状態・業界・工程・技術）が出る。
- プラグはつまんで抜ける。コンセントの近くで離すと差さる（輪が一度広がる）。どこにも差さずに離すと、ぶら下がり、モニターは「プラグを差すと、その仕事が見られます」になる。
- 仕事の行はボタンでもある（押す・Enter で、プラグがそこへ飛んで差さる）。`aria-pressed` と、短い状態の文（「… を表示しています」「プラグを抜きました」）の `aria-live="polite"`。
- 差さっているケーブルには砂粒（データ）が流れる。最初は今の仕事に差さっている。
- 狭い画面では一覧の下にモニターを置き、ケーブルは右の余白を通る。JS 無しでは全部の仕事を縦に並べる（今までの一覧）。

## D 道具箱（04 AI と開発）

- AI と開発の道具（Claude Code・Copilot・Codex・MCP・AGENTS.md など、この段の文に出てくるもの）を、角の丸い札の剛体（matter.js）として箱に注ぐ。傾けると滑って積み重なり、つまんで投げられる。「揺らす」で跳ね上げる。
- 札の幅は文字の幅から決める。AI の道具はティール、設定ファイルは面＋枠、ほかは地の色。
- 箱は飾り。同じ内容は下のカードの文に書いてある。

## 傾きのつまみ（PC）

- lg 以上の左の「流れ」の下に「傾き」のつまみ（丸い面の上の点を引く・矢印キー・ダブルクリックで下向き）。全部の物理が同じ向きに傾く。
