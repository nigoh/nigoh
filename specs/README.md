# SDD (Spec-Driven Development) 仕様書

このディレクトリには、CC-SDD（Cursor Composer + Spec-Driven Development）方式の仕様書を格納します。

## ワークフロー

1. **Spec（仕様）を書く** — 機能・ページ・コンポーネントの要件を Markdown で定義
2. **エージェントに仕様を渡す** — 仕様ファイルを参照して実装を依頼
3. **受入条件で検証** — 仕様に記載した受入条件をもとに動作確認
4. **仕様を更新** — 変更があれば仕様ファイルを先に更新してから実装に反映

## ディレクトリ構造

```
specs/
├── README.md          # このファイル
├── site.spec.md       # サイト全体仕様
├── components/        # コンポーネント仕様
│   └── *.spec.md
└── pages/             # ページ仕様
    └── *.spec.md
```

## 仕様テンプレート

各仕様ファイルは以下のテンプレートに従います:

```markdown
# [コンポーネント/ページ名]

## 目的
何を実現するか

## 入力 (Props / パラメータ)
- prop名: 型 — 説明

## 出力 / 表示
期待する表示内容・レイアウト

## デザイン指針
- カラー、フォント、レスポンシブ対応等

## 受入条件
- [ ] 条件1
- [ ] 条件2
```
