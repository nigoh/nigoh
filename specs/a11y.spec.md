# アクセシビリティ & コントラスト監査（横断）

## 目的

サイト全体（`src/pages/index.astro` 全セクション + `src/components/**` + `BaseLayout` + `global.css`）の
WCAG 2.1 AA 準拠を横断監査し、構成主義パレット（`tailwind.config.mjs` の `constructivist.*`）内での
是正方針と受入条件を定める。Round 2 で是正済みの Hero 小ラベル（赤→cream）と同種の問題を洗い出す。

対象パレット: red `#D62828` / black `#1A1A1A` / cream `#F5F0EB` / gray `#8B8680` / darkgray `#3D3A37`

## コントラスト比一覧（実測）

AA 基準: 通常テキスト 4.5:1 / 大テキスト（24px 以上、または 18.66px 以上の太字）3:1。

| 前景 on 背景 | 比 | 通常(4.5) | 大(3.0) |
|---|---|---|---|
| cream on black | 15.37:1 | OK | OK |
| black on cream | 15.37:1 | OK | OK |
| darkgray on cream | 9.98:1 | OK | OK |
| cream on darkgray | 9.98:1 | OK | OK |
| gray on black | 4.82:1 | OK | OK |
| red on cream | 4.42:1 | **NG** | OK |
| cream on red | 4.42:1 | **NG** | OK |
| black on red | 3.48:1 | NG | OK |
| red on black | 3.48:1 | NG | OK |
| gray on cream | 3.19:1 | **NG** | OK |
| gray on darkgray | 3.13:1 | NG | OK |
| gray on red | 1.39:1 | **NG** | **NG** |

このパレットの帰結:
- **gray は cream 上で通常テキストに使えない**（3.19:1）。cream 上の小テキストは darkgray を使う。
- **red は通常テキストではどの背景でも AA 未達**（cream 4.42 / black 3.48）。red の文字は「大テキスト（24px+ または 18.66px+ bold）」に限定する。小ラベル（text-xs 等）には red を使わない。
- **gray on red / cream on red は要注意**。赤帯の上は cream（大サイズ）のみ可。赤背景に gray テキストは禁止。

### R-FOCUS（global.css に追加）

`:focus-visible` を全インタラクティブ要素に定義する。パレット内で背景に応じてリング色を変える:

```css
:focus-visible {
  outline: 3px solid #D62828;      /* constructivist-red（cream 背景で視認） */
  outline-offset: 2px;
}
/* 黒背景セクション内では cream リング（red on black は弱い） */
.bg-constructivist-black :focus-visible {
  outline-color: #F5F0EB;          /* constructivist-cream */
}
```

受入: Tab 操作でナビ6項目・Hero CTA・各カードリンク・Contact CTA・モバイルメニューボタンに
明確なリングが出る。黒背景でも消えない。

### R-MOTION（reduced-motion 網羅）

1. `FadeIn.tsx`: `useReducedMotion()` を導入し、reduced 時は `immediate: true`（最終状態を即時表示、translate 無効）。
2. `AnimatedSkillBar.tsx`: 同上。`spring`/`numberSpring` に `immediate: reduceMotion`。
   reduced 時はバーは最終幅・数値は最終値で即表示。
3. `AnimatedTimeline.tsx`: 同上。`trail`/`lineSpring` に `immediate: reduceMotion`。
4. `global.css`: 保険として CSS アニメ全体を抑制:

```css
@media (prefers-reduced-motion: reduce) {
  html { scroll-behavior: auto; }
  *, *::before, *::after {
    animation-duration: 0.001ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.001ms !important;
  }
}
```

`ConstructivistCanvas` と `AnimatedHero` は対応済みのため変更不要。

- AI カードアイコン SVG L391/406/421/436 に `aria-hidden="true"`。
- Zenn emoji span L595: `role="img" aria-label="article emoji"` を削除し `aria-hidden="true"` に置換（純装飾）。
- （任意）Header ハンバーガー SVG L42 に `aria-hidden="true"`。
- （任意）言語分布の装飾バー コンテナ L337 に `aria-hidden="true"`（凡例が別にあるため）。
- （任意）Hero avatar alt を "H.NIGO のプロフィール写真" に。

### R-SEMANTIC（任意・低優先）

- 各 `<section id>` に `aria-labelledby` を付け、対応 `h2` に `id` を付与（landmark とラベルの関連付け）。
